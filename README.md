# csu_network_login
中南大学校园网自动检测
中南大学 Dr.COM 校园网自动登录保活脚本
 
简洁稳定、安全无后门，解决校园网频繁掉线、需手动认证的问题。
 
功能介绍
 
- 自动检测网络状态，每30秒检查一次是否在线
- 认证过期/断网时，自动重新登录
- 连续2次检测离线才登录，避免误判
- 支持校园网/电信/联通/移动账号
- 搭配 VBS 可后台无窗口运行
- 支持设置开机自启动，开机自动连网
 
支持账号类型
 
- 校园网用户：学号（无后缀）
- 校园电信：学号@dx
- 校园联通：学号@lt
- 校园移动：学号@cmccn（以页面显示为准）
 
使用说明
 
1. 打开  campus_network_login.py ，填写  USERNAME  和  PASSWORD 
2. 配置  run_wifi.vbs  中 Python 路径与脚本路径
3. 双击 VBS 后台运行，或放入启动文件夹实现开机自启
4. 任务管理器可查看 Python 进程，Ctrl+C 可退出
 
安全说明
 
- 纯本地运行，无隐私收集、无数据上传
- 仅访问学校认证服务器，安全无风险
- 代码开源透明，无捆绑、无后门
